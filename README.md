# OverTheWire Bandit Walkthrough

A command-focused walkthrough for Bandit Levels 0–33.

## Contents

Each level has its own `solution.md` containing:
- Commands used to solve the challenge
- A short explanation of why the approach works

## Security note

This repository intentionally does not include the actual Bandit passwords or private SSH keys.

## Environment

The walkthrough primarily uses Linux shell commands and Windows CMD for local Git operations where appropriate.
